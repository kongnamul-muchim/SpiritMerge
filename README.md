# Spirit Merge — 정령 머지 & 자동 전투

**정령을 수집하고 합성해 더 강한 정령을 만들고, 자동 전투로 스테이지를 밀어 올리는 모바일 방치형(Idle) RPG**

Unity 6으로 개발한 WebGL 플레이 가능한 포트폴리오 게임입니다. 브라우저에서 바로 실행할 수 있습니다.

## 🎮 게임 개요

정령 머지(합성) + 자동 전투 + 파견(의뢰) 시스템이 결합된 **무한 성장 구조**의 방치형 RPG입니다.

```
전투 클리어 → 골드 획득 → 정령 소환 → 머지 합성(성급↑) → 파티 강화
                                                  ↓
                                         더 높은 스테이지 도전 (반복)
                                                  ↓
              안 쓰는 정령 → 파견(의뢰) → 루비 획득 → 영구 업그레이드
                                                  ↓
                              소환/머지/전투 가속 → 절대 막히지 않는 성장
```

## ✨ 주요 기능

### 1. 머지 시스템 (Merge Board)
- **4x4 보드**에서 정령을 클릭/드래그로 합성
- 같은 속성 + 같은 성급이 만나면 **한 단계 위 정령**으로 합성 (Lv.1 → Lv.2 → ... → Lv.5+)
- 합성 시 성급이 올라 **스프라이트가 진화**하고 스탯(전투력)이 실제로 증가
- 최대 성급 도달 시 노란 테두리 표시

### 2. 자동 전투 (Auto Battle)
- 파티에 배치된 정령들이 **자동으로 적을 공격** (방치형)
- 웨이브 기반 진행 + 보스 스테이지
- **파티 통합 HP** — 정령 개별이 아닌 파티 전체 체력으로 전투
- 반복 모드(현재 스테이지 유지) / 등반 모드(다음 스테이지) 선택 가능

### 3. 6가지 속성 & 상성
| 속성 | 강함 → | 약함 ← |
|------|--------|--------|
| 🔥 불 | 🌿 땅 | 💧 물 |
| 💧 물 | 🔥 불 | 🌿 땅 |
| 🌿 땅 | 💧 물 | 🔥 불 |
| ⚡ 바람 | 💧 물 | 🌿 땅 |
| 🌑 어둠 | ✨ 빛 | 🌑 어둠 |
| ✨ 빛 | 🌑 어둠 | ✨ 빛 |

- 속성 시너지: 불(공격력) / 물(공격속도) / 바람(치명타) / 땅(통합 HP) / 어둠(흡혈·공격) / 빛(방어·회복)
- 물 스플래시 / 땅 광역 등 속성별 공격 방식 차별화

### 4. 파티 편성 (Party)
- 4슬롯 파티에 정령 드래그/클릭 배치
- 빛과 어둠 정령은 함께 편성 불가 (상성 설계)

### 5. 업그레이드 트리 (25노드)
- **골드 탭**: 공격력/방어력/체력/치명타 등 10종
- **레벨 탭(SP)**: 자동 소환/2성 확률/소환 할인/머지 보너스 등 5종
- **루비 탭**: 프리미엄 스탯 10종
- 0레벨 = 수치 0, 강화는 1레벨부터 적용

### 6. 의뢰 시스템 (3탭)
- **파견**: 안 쓰는 정령 2마리를 의뢰에 보내 루비 획득 (보너스 조건 매칭 시 추가 보상)
- **미션**: 일일/주간 10종 미션 (몬스터 처치, 머지, 파견, 레벨업 등)
- **레이드**: 60초 페이즈 보스전 — 보스는 죽지 않고 더 강해지며, 점수에 따라 보상

### 7. 도감 (30종)
- 6속성 × 5성급 = 30종 정령 수집 현황
- 성급별 진화 스프라이트 확인

### 8. 자동 저장 시스템
- 모바일 표준 자동 저장: 30초 주기 + 주요 이벤트(재화/소환/머지/파견/클리어/업그레이드) + 앱 백그라운드/종료 시
- **원자적 쓰기 + 백업 파일**로 강제종료에도 데이터 손실 방지
- **오프라인 경과 반영** — 앱을 끈 동안에도 파견 시간이 흘러 완료 처리

## 🛠 기술 스택

| 분야 | 사용 |
|------|------|
| 게임 엔진 | Unity 6 (6000.5.5f1) |
| 언어 | C# |
| UI | uGUI (런타임 동적 생성) |

```
Assets/Scripts/
├── Battle/        # 전투 시스템 (WaveController, Monster, SpiritUnit, WaveCalculator)

├── Manager/       # GameManager, BattleManager, DataManager (저장)
├── Core/Systems/  # PlayerService, DispatchService, MissionService, RaidService
├── Data/          # SpiritData, StageData, Enums, SaveData
├── Presentation/  # UI (RequestUI, RaidBattle, DispatchFormationUI, CliTestSuite)
└── Editor/        # 에디터 도구 (CliServer, ProjectSetup, UI 빌더)
```

## 🔨 빌드 방법

```powershell
# WebGL 빌드 (GitHub Pages 배포용)
.\unity.ps1 build-webgl

# Android APK 빌드 (Android 모듈 필요)
.\unity.ps1 build-android
```

빌드 결과: `Builds/WebGL/` (index.html — 웹 서버로 서빙)

## 🧪 테스트

```powershell
# Unity 에디터 실행 후
python cli-client.py fulltest   # 전체 시스템 14개 통합 검증
python cli-client.py errors     # 컴파일 에러 확인
```

## 📌 포트폴리오 어필 포인트

1. **머지 + 자동 전투 + 파견** — 3개 핵심 루프가 상호작용하는 완성형 게임 디자인
2. **이중 재화 경제** (골드/루비) — 재화의 획득·소비 구조 설계
3. **무한 성장 구조** — 절대 막히지 않는 방치형 루프
4. **데이터 안전** — 강제종료/오프라인 대응 자동 저장 시스템
5. **CLI 자동화 테스트** — 14개 시스템 통합 검증 파이프라인
6. **WebGL 실기동** — 브라우저에서 바로 플레이 가능
