## Variant: Mobile Merge Defense (9:16 Portrait)

### Design stance
모바일 세로형(9:16) 머지 디펜스 게임 — Cat Heroes / Merge God 스타일.
한 손 조작에 최적화된 레이아웃, 상단 전장 + 하단 머지보드의 명확한 분할.

### Layout breakdown

**화면 비율:** 390×844px (9:16 portrait)

**영역 분할:**
| 영역 | 비율 | 높이 | 설명 |
|------|------|------|------|
| Top bar | ~5% | 44px | 스테이지명, 골드/다이아 |
| Battle field | ~40% | flex-1 | 2D 전장, 적 웨이브, 정령 전투 |
| Merge board | ~48% | 55% 고정 | 4×4 타일 그리드 + 컨트롤 |
| GNB | ~7% | 56px | 하단 네비게이션 탭 |

### Battle field
- 아이소메트릭 그라운드 느낌 (체크보드 패턴)
- 적 유닛 3마리 (체력바 + 부동 애니메이션)
- 정령 유닛 4마리 (공격 이펙트 + 부동 애니메이션)
- 웨이브 인디케이터 + 경로 웨이포인트

### Merge board
- 4×4 통합 그리드 (좌/우 분할 없음)
- 타일 1개당 넉넉한 크기 (화면 폭의 23%)
- 속성별 테두리 색상: 🔥불/💧물/🌿자연/⚡번개
- 각 타일: 아이콘 + 레벨 배지 + 별점 + 속성 태그
- 빈 타일은 "+"로 표시

### Controls
- [정령 소환] 메인 버튼 (큼직함, 파랑 그라데이션)
- 자동 합성 / 정리 보조 버튼 (아이콘)

### GNB
- 5개 탭: 전투 | 파티 | 소환 | 도감 | 의뢰
- 아이콘 + 텍스트 형태
- 활성화 탭 상단 바 표시

### Notes
- `tile:active { transform: scale(0.95) }` — 터치 피드백
- `touch-action: manipulation` — 더블탭 줌 방지
- 팝업은 모달 오버레이 + 블러 처리
