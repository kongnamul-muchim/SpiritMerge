# Spirit Merge: Game Design v2 (포트폴리오 스펙)

**컨셉:** 정령 컬렉팅 + Auto-Battle + Merge Idle RPG
**정령사 삭제** → 오직 정령들이 전투하고 합성됨

---

## 1. 속성 시스템 (Element) — 4속성

| 속성 | 아이콘 | 강함 → | 약함 ← |
|------|--------|--------|--------|
| 🔥 불 | 🔥 | 🌿 자연 | 💧 물 |
| 💧 물 | 💧 | 🔥 불 | 🌿 자연 |
| 🌿 자연 | 🌿 | 💧 물 | 🔥 불 |
| ⚡ 번개 | ⚡ | 💧 물 | 🌿 자연 |

**상성 데미지:** 강함 = 1.5배 / 약함 = 0.75배

---

## 2. 정령 등급 & 머지 레벨

```
Merge Lv.1  ★☆☆☆☆  (기본, 2마리 합성)
Merge Lv.2  ★★☆☆☆  (3마리)
Merge Lv.3  ★★★☆☆  (3마리)
Merge Lv.4  ★★★★☆  (4마리)
Merge Lv.5  ★★★★★  (4마리)
Merge Lv.6  ★★★★★★ (5마리) → 최대
```

- Lv.1→2만 **2마리** (초반 빠른 성장)
- Lv.5→6은 **5마리** (후반 도전 과제)
- 레벨당 능력치: 공격력 +40%, 체력 +30%

**도감 등록:** 각 정령 × 각 속성 × 각 레벨 = 수집 요소

---

## 3. 파티 시스템 (Party)

- **4슬롯** 고정
- 파티는 정령 보관함(Collection)에서 드래그로 배치
- **속성 시너지:** 3+ 같은 속성 = 전체 공격력 +15%
- **풀파티 보너스:** 4슬롯 모두 채우면 추가 HP +10%

---

## 4. 전투 시스템 (Battle)

### 전투 흐름
```
Stage 3-8 시작
├─ Wave 1/7: 적 3마리 등장
├─ Wave 2/7: 적 4마리
├─ ...
└─ Wave 7/7: 보스 등장
     → 클리어 → 보상 + 다음 스테이지
     → 실패 → 정령 부활 후 재도전
```

### 전투 알고리즘
```
1. 1초마다 각 정령이 자동 공격
2. 가장 가까운 적 대상
3. 데미지 = 공격력 × 속성보정 ÷ 적 방어력
4. 적 처치 시 다음 웨이브
5. 모든 정령 사망 = 전투 실패
```

## 5. 핵심: 두 가지 성장 축

### 🅰️ 기본 루프 (골드 → 전투력)
```
전투 클리어 → 🪙 골드 획득
  → 정령 소환 (500🪙)
  → 머지 보드에서 합성
  → 정령 레벨업 → 파티 강화
  → 더 높은 스테이지 도전 ✅
```

### 🅱️ 메타 루프 (다이아 → 업그레이드)
```
파티에 안 쓴 정령을 의뢰(파견) 보냄
  → 💎 다이아 획득
  → 업그레이드 탭에서 영구 업그레이드
  → 머지가 더 쉬워짐 / 보드 확장 / 소환 할인
  → 더 빠른 성장 → 더 높은 스테이지 ✅
```

### 두 루프의 관계
```
🅰️ 기본 루프 (골드) ──→ 전투력 ↑ ──→ 더 높은 스테이지
       ↑                          ↓
       │                    🅱️ 메타 루프 (다이아)
       │                          ↓
       └── 업그레이드로 가속 ──────┘

→ 절대 막히지 않는 무한 성장 구조!
```

## 6. 의뢰 시스템 (Commission / Dispatch)

### 개념
```
파티에 속하지 않은 정령들을 "파견" 보내서
다이아 + 특수 재화를 벌어오는 시스템

보드가 꽉 차도 의미 있는 행동 가능!
```

### 상세
| 항목 | 내용 |
|------|------|
| 파견 슬롯 | 기본 2칸 (업그레이드로 최대 5칸) |
| 정령 선택 | 파티 미배치 정령 중 선택 (1~3마리) |
| 파견 시간 | 30분 / 1시간 / 3시간 / 8시간 |
| 보상 | 💎 다이아 + 특수 재화 |
| 성공률 | 보낸 정령 전투력 합산 → 높을수록 추가 보상 |
| 리스크 | 실패해도 기본 보상은 획득 |

### 다이아 사용처 (업그레이드 전용)

```
💎 다이아 = 절대 골드로 살 수 없는 프리미엄 재화
              (현질 개념 없음 — 의뢰로만 획득)
```

## 7. 업그레이드 시스템 (Upgrade Tree)

업그레이드 탭(GNB)에서 다이아로 영구 업그레이드.

### 🔵 머지 관련 (보드 안 막히게)

| 업그레이드 | 효과 | 1레벨 | MAX | 총 다이아 |
|-----------|------|-------|-----|----------|
| 보드 확장 | 머지 보드 +1열 (세로 확장, 스크롤) | 4×4(16) | 무한 | 💎2,500 |
| 자동 합성 | n초마다 보드 위 합성 가능한 정렬 자동 합성 | 30초마다 1회 | 1초마다 1회 | 💎1,200 |
| 합성 할인 | 합성 필요 마리수 -1 (Lv.1만) | - | 2→1 | 💎300 |
| 소환 할인 | 정령 소환 비용 -10% | -50🪙 | -250🪙 | 💎800 |
| 머지 경험치 | 합성 시 추가 경험치 | +10% | +100% | 💎600 |
| 보드 자동정리 | 5초마다 타일 정렬 | - | ON | 💎400 |

### 🟡 의뢰 관련

| 업그레이드 | 효과 | 1레벨 | MAX | 총 다이아 |
|-----------|------|-------|-----|----------|
| 파견 슬롯 | 동시 파견 가능한 슬롯 +1 | 2 | 5 | 💎1,500 |
| 파견 보상 | 의뢰 보상량 +20% | +20% | +200% | 💎1,000 |
| 파견 시간 단축 | 전체 파견 시간 -10% | -10% | -50% | 💎800 |
| 고급 의뢰 |稀有 등급 의뢰 등장 확률 | - | +30% | 💎600 |

### 🔴 전투 관련

| 업그레이드 | 효과 | 1레벨 | MAX | 총 다이아 |
|-----------|------|-------|-----|----------|
| 전투 속도 | 전투 2배속 | - | ON | 💎500 |
| 자동 전투 | 꺼도 자동 진행 | - | ON | 💎300 |
| 골드 보너스 | 스테이지 클리어 골드 +20% | +20% | +200% | 💎800 |
| 경험치 보너스 | 정령 경험치 +10% | +10% | +100% | 💎600 |

## 9. 성장 사이클 (최종)

```
⚔️ 전투
  ↓  골드
✨ 정령 소환 → 보드에 정령 추가
  ↓
🔄 머지 합성 → 더 강한 정령
  ↓                     ↓
⚔️ 파티 교체       📋 의뢰 파견 (안 쓰는 정령)
  ↓                     ↓
더 높은 스테이지    💎 다이아 획득
  ↓                     ↓
🔄 반복...          🔧 업그레이드 구매
                       ↓
              보드↑ / 합성↑ / 할인↑ / 파견↑
                       ↓
              🅰️ 기본 루프 가속 → 절대 안 막힘!
```

### 소환 비용 공식
```
소환 비용 = 500 + (챕터 - 1) × 300

챕터 1: 500🪙    (1-8 클리어 시 보상 ≈ 500×6 = 3000 가정)
챕터 2: 800🪙    (2-8 클리어 시 보상 ≈ 800×6 = 4800)
챕터 3: 1100🪙
터 4: 1400
...
```

**보석 업그레이드: "소환 할인" (영구)**
- Lv.1: -100🪙
- Lv.2: -200🪙
- ...

## 10. 테이지 시스템 (최종)

### 핵심 공식
| 항목 | 공식 | 예시 (1챕터) |
|------|------|-------------|
| 총 몬스터 수 | `챕터 × 10 + 스테이지 × 2` | 1-1=12, 1-5=20, 1-10=30 |
| 웨이브 수 | `챕터 + 4` | 1챕터=5웨이브 |
| SpawnPoint | 항상 5개 (일렬 배치) | — |
| 소환 비용 | `500 + (챕터-1) × 300` | 챕터1=500, 챕터2=800 |

### 웨이브별 몬스터 분배 로직
```
총 30마리, 5웨이브
→ 1~5 랜덤 분배 (단, 합계 = 30)
→ 마지막 웨이브(5)는 보스 1마리만
→ 앞 4웨이브에 29마리 분배
```

### 보스 스테이지 (n-5, n-10)
- 마지막 웨이브 = **보스 1마리만 등장**
- 보스 HP = 일반 몬스터 × 10
- 보스 공격력 = 일반 몬스터와 **동일**

### 스테이지 속성 순서 (무한 반복)
```
1챕터: 🔥 불    5챕터: 🔥 불
2챕터: 💧 물    6챕터:  물
3챕터: 🌿 자연  7챕터: 🌿 자연
4챕터: ⚡ 번개  8챕터: ⚡ 번개
```

### 아군 정령 속성별 특성
| 속성 | 공격 방식 |
|------|----------|
| 🔥 불 | 강한 한방 (높은 데미지, 느린 속도) |
| 💧 물 | 빠른 공격 (낮은 데미지, 빠른 속도) |
| 🌿 자연 | 높은 체력 (탱커) |
|  번개 | 광역 피해 (다수 동시 공격) |

### 적 몬스터
- **SpawnPoint 5개** (일렬 배치, 움직임 없음)
- 웨이브 시작 시 점진적 등장
- 사망 시 천천히 사라짐
- 모든 몬스터 동일 공격 패턴 (아직 구현 예정)

## 12. 포트폴리오 어필 포인트

```
1. SOLID 원칙 + VContainer DI — 클린 아키텍처
2. Merge + Auto-Battle + Dispatch — 3개의 상호작용 시스템
3. 두 가지 재화 경제 (골드/다이아) — 게임 디자인 깊이
4. 절대 막히지 않는 성장 구조 — "완성된 게임" 느낌
5. 40종 도감 + 50스테이지 — 컨텐츠 볼륨
6. CLI 자동화 — 개발 생산성
7. WebGL 빌드 — 실제 플레이 가능
```
