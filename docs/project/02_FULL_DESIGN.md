## 1. 속성 시스템

### 기본 4속성

| 속성 | 영문 (Enum) | 강함(1.5배) → | 약함(0.75배) ← |
|------|------------|--------------|---------------|
| 🔥 불 | `Fire` | 자연 | 물 |
| 💧 물 | `Water` | 불 | 자연 |
| 🌿 자연 | `Earth` (Nature) | 물 | 불 |
| ⚡ 번개 | `Wind` (Thunder) | 물 | 자연 |

### 확장 2속성

| 속성 | 영문 | 강함 | 약함 |
|------|------|------|------|
| 🌑 어둠 | `Dark` | 빛 | 빛 |
| ✨ 빛 | `Light` | 어둠 | 어둠 |

### 상성 데미지 계산
```
최종 데미지 = 공격력 × 속성보정 ÷ 적 방어력
- 강함 (유리): × 1.25 (또는 × 1.5)
- 약함 (불리): × 0.85 (또는 × 0.75)
- 동일: × 1.0
```

## 4. 전투 시스템

### 전투 흐름
```
Stage 3-8 시작
├─ Wave 1/7: 적 3마리 등장 (웨이브 진입 표시 2초)
├─ Wave 2/7: 적 4마리
├─ ...
└─ Wave 7/7: 보스 등장 (HP 10배, 공격력 동일)
     → 클리어 → 보상 + 다음 스테이지
     → 실패 → 정령 부활 후 재도전
```

### 전투 알고리즘
1. 1초마다 각 정령이 자동 공격
2. 가장 가까운 적 대상
3. 데미지 = 공격력 × 속성보정 ÷ 적 방어력
4. 적 처치 시 다음 웨이브
5. 모든 정령 사망 = 전투 실패

### 정령 속성별 역할
| 속성 | 역할 |
|------|------|
| 🔥 불 | 강한 한방 (높은 공격력, 느린 공격속도) |
| 💧 물 | 빠른 공격 (낮은 공격력, 빠른 공격속도) |
| 🌿 자연 | 탱커 (높은 체력/방어력) |
| ⚡ 번개 | 광역 (범위 데미지) |

### 몬스터
```
SpawnPoint 5개 일자 배치 (고정)
몬스터는 움직이지 않음 (제자리에서 공격)

totalMonsters = chapter × 5 + stage
waves = chapter + 4
보스: n-5, n-10 스테이지 (HP 10배)
```
