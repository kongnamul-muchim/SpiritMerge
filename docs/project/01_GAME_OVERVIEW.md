# Spirit Merge — 게임 개요

> **버전:** 2.0 (포트폴리오 스펙)
> **최종 업데이트:** 2026-07-29
> **개발 엔진:** Unity 6000.5.5f1

---

## 🎮 게임 컨셉

**정령 컬렉팅 + Auto-Battle + Merge Idle RPG**

플레이어는 정령을 소환하여 머지(합성)로 강화하고, 자동 전투를 통해 스테이지를 클리어하는 Idle RPG입니다.

> "정령사는 없다 — 오직 정령들이 전투하고 합성된다."

## 🎯 코어 게임플레이

### 기본 루프 (🅰️ 골드)
```
전투 클리어 → 골드 획득
  → 정령 소환 (500🪙)
  → 머지 보드에서 합성
  → 정령 레벨업 → 파티 강화
  → 더 높은 스테이지 도전 ✅
```

### 메타 루프 (🅱️ 다이아)
```
파티에 안 쓴 정령을 의뢰(파견) 보냄
  → 다이아 획득
  → 업그레이드 탭에서 영구 업그레이드
  → 머지가 더 쉬워짐 / 보드 확장 / 소환 할인
  → 더 빠른 성장 → 더 높은 스테이지 ✅
```

## 🏗 핵심 시스템

| 시스템 | 설명 | 상태 |
|--------|------|------|
| 🎴 **소환** | 골드를 소모하여 랜덤 정령 생성 | ✅ 완료 |
| 🔄 **머지** | 같은 속성 + 같은 레벨 정령 합성 → 레벨업 | ✅ 완료 (버그 수정중) |
| ⚔️ **전투** | 자동 진행, 웨이브 기반, 스테이지 클리어 | 🔧 진행중 |
| 👥 **파티** | 보유 정령 → 전투 슬롯 배치 (4슬롯) | ❌ 미구현 |
| 📋 **의뢰** | 미사용 정령 파견 → 다이아 획득 | ❌ 미구현 |
| 🔧 **업그레이드** | 다이아 소모 → 영구 능력치 향상 | ❌ 미구현 |
| 📖 **도감** | 수집한 정령 기록 | ❌ 미구현 |

## ⚡ 속성 시스템 (4+2)

| 속성 | 영문 | 아이콘 | 강함(1.5배) → | 약함(0.75배) ← |
|------|------|--------|--------------|---------------|
| 🔥 불 | Fire | 🔥 | 자연 | 물 |
| 💧 물 | Water | 💧 | 불 | 자연 |
| 🌿 자연 | Nature/Earth | 🌿 | 물 | 불 |
| ⚡ 번개 | Thunder/Wind | ⚡ | 물 | 자연 |
| 🌑 어둠 | Dark | 🌑 | 빛 | 빛 |
| ✨ 빛 | Light | ✨ | 어둠 | 어둠 |

> 기본 4속성 (불/물/자연/번개), Light/Dark는 확장 속성

## 📊 스테이지 구조

| 챕터 | 이름 | 스테이지 | 속성 | 웨이브 수 |
|------|------|---------|------|----------|
| 1 | 불의 숲 | 1-1 ~ 1-10 | 🔥 불 | 5 |
| 2 | 물의 숲 | 2-1 ~ 2-10 | 💧 물 | 6 |
| 3 | 숲의 길 | 3-1 ~ 3-10 | 🌿 자연 | 7 |
| 4 | 번개의 숲 | 4-1 ~ 4-10 | ⚡ 번개 | 8 |
| 5 | 불의 성소 | 5-1 ~ 5-10 | 🔥 불 | 9 |

- **총 스테이지:** 50개 (5챕터 × 10스테이지)
- **보스:** n-5, n-10 스테이지 (HP 10배, 공격력 동일)
- **소환 비용:** 500 + (챕터-1) × 300
